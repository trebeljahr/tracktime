# Getting help

tracktime is maintained by one person in their spare time. Picking the right
place is most of what makes a question answerable.

## Where to go

| You want to | Go here |
|---|---|
| Ask how something works, or get help self-hosting | [Question form](https://github.com/trebeljahr/tracktime/issues/new?template=question.yml) — GitHub Discussions are not enabled here, so questions go in the issue tracker |
| Report something that behaves wrongly | [Bug report form](https://github.com/trebeljahr/tracktime/issues/new?template=bug_report.yml) |
| Suggest a change or addition | [Feature request form](https://github.com/trebeljahr/tracktime/issues/new?template=feature_request.yml) |
| Report a security vulnerability | **Not a public issue.** Email <ricotrebeljahr@gmail.com> — see [SECURITY.md](SECURITY.md) |
| Fix it yourself | [CONTRIBUTING.md](CONTRIBUTING.md) |

Read the [README](README.md) first. Its "Not there yet" section lists what is
deliberately unbuilt, which answers a fair number of questions before they are
asked.

## What makes a question answerable

- **Which surface** — web app, browser extension, Raycast extension, server,
  or one of the desktop/mobile shells. They share a backend and almost nothing
  else, and the answer usually differs per surface.
- **Hosted or self-hosted**, and if self-hosted, the commit you are on.
- **What you did, what happened, what you expected** — in that order, concretely.
- **The actual error text**, copied rather than described. Server logs and the
  browser console both help.

## What to expect

Best-effort, not contractual. This is a side project with no support
commitment: a reply may take days, and questions that already have an answer in
the README, [CONTRIBUTING.md](CONTRIBUTING.md) or `docs/deploy.md` may get a
link rather than a fresh explanation.

Feature requests get read, and some get declined — the scope is opinionated on
purpose. A decline is not a judgement of the idea.

Security reports are the exception and are prioritised; see
[SECURITY.md](SECURITY.md) for the expected timelines.
